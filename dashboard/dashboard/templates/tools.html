Tools

Local dev/diagnostic scripts -- each opens its own window (MuJoCo viewer or RViz) and keeps running independently of the dashboard once launched. Fields you set are remembered between visits.

save_pose.py

Interactively pose the dog in the MuJoCo viewer, then save the final joint angles to a .txt file for reference. Drag joints / let it settle under gravity, then close the window -- qpos at that moment gets saved.

manual_motor_control

Drive each motor's target by hand through the real DogEnv.step() path (not the raw MuJoCo Control tab). Keys: 1-8 select motor, Up/Down nudge by step-deg, R reset, Space pause.

verify_belt_decoupling

Sweeps one leg's thigh back and forth while holding its calf fixed at an absolute target -- if the belt/pulley decoupling fix is working, the calf stays pointing the same direction the whole time.
unchecked = DogEnv's own default (1000). --full-range auto-lengthens period to stay under this.
0 = run until the viewer window is closed

dog_view.launch.py

Full 4-leg dog in RViz with slider-controlled joints. No configurable arguments.
